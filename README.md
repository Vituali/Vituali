### 🧠 Nexus | Integrated Telecom Operations Platform
**Private work project · Active development**

An integrated platform developed around real needs in a telecom operation, combining customer service workflows, commercial management, network visibility, documentation and internal automation.

**Selected engineering areas:**
- **Operational CRM:** workflows, lead management, task boards, service-order auditing and operational metrics.
- **Knowledge management:** a searchable wiki with public/internal access, editorial review, versioning and role-based permissions.
- **System integrations:** a Chrome Manifest V3 extension connecting operational workflows across existing systems.
- **Network operations:** OLT/ONU inventory data, connectivity diagnostics and monitoring-oriented dashboards.
- **Distributed services:** a Next.js application, Python automation services and PostgreSQL, with Docker-based deployment.
- **Engineering practices:** schema-based contracts, automated checks, documentation gates, GitHub Actions and self-hosted runners.

**Technologies:** `Next.js 15` `React 19` `TypeScript` `Python` `PostgreSQL` `Drizzle` `Docker` `GitHub Actions` `Fumadocs` `Zod`

### 🏭 Intelligent Production Line Supervisor
**Mechatronics Engineering · Academic project**

A simulated automated biscuit production line with six stations, real-time supervision, failure injection and industrial performance indicators.

- Live monitoring of **OEE, Availability, Performance, Quality, Throughput and Takt Time**.
- 2D production-line visualization, machine states, alerts and historical metrics.
- Configurable production speed and fault simulation for engineering scenarios.
- React/TypeScript frontend with Zustand, Chart.js and optional Firebase persistence.

**Technologies:** `React` `TypeScript` `Vite` `Zustand` `Tailwind CSS` `Chart.js` `Firebase`

*Academic repository currently private.*
